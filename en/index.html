Features

Maximum FPS,
zero fiddling

The client downloads Minecraft, Fabric, Java and performance mods on its own. All you do is hit Play.

Sodium and FerriteCore

Preinstalled and always on: more FPS and less RAM. Lithium, ImmediatelyFast, EntityCulling and ModernFix are one click away.

Modrinth + CurseForge

Search, install, enable and remove mods. Required dependencies are added automatically, and only builds for your game version are shown.

Instant launch

Files download in parallel and are checksum-verified. Later launches check everything in a fraction of a second.

No Java needed

The client fetches Mojang's official Java for each game version. Nothing to install by hand.

Tuned JVM

Tuned G1, or ZGC for strong PCs, plus compact object headers on new Java. The recommended RAM is picked for your machine.

Microsoft sign-in

Like Lunar: Microsoft's sign-in page opens in its own window and closes by itself. The client never sees your password.

Interface

Clean and fast

Dark theme, everything important on one screen. English and Russian. Browse the screenshots →

FAQ

Questions

Is it free?

Yes. The client is free and open source. To play you need Minecraft Java Edition on your Microsoft account.

Which Minecraft versions are supported?

Every release from 1.20 to the newest that Fabric, Sodium and FerriteCore support. The latest is picked by default, and you can switch on the home screen.

Can I add my own mods?

Yes. Search Modrinth or CurseForge in the Mods tab and install with one click. You can also drop a .jar into the mods folder; the "Mods folder" button opens it.

Why does Windows/macOS show a warning?

The builds don't have a paid code signature yet. The code is open on GitHub, and the installers are built automatically from source by GitHub Actions.

How much RAM should I give it?

The client suggests a value: usually 4 GB, or 6 GB on PCs with 16 GB or more. More isn't faster: too much memory causes long garbage-collection pauses.

Ready to play?

Download Stray Client, sign in with Microsoft and hit Play. It handles the rest.
