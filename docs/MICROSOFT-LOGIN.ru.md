# Вход через Microsoft в Stray Client — настройка (≈ 10 минут)

Stray Client уже работает: игра запускается через **официальный Minecraft Launcher**, и лицензию проверяет он.
Чтобы входить в аккаунт Microsoft **прямо в Stray Client** (как в Lunar: отдельное окно входа, несколько аккаунтов, смена скина в один клик), клиенту нужен собственный **Microsoft Client ID**. Его может создать только владелец проекта — это бесплатно.

## Что понадобится

- Аккаунт Microsoft.
- Карта **Visa или Mastercard** (подходит и дебетовая) — Microsoft использует её только для проверки личности при создании бесплатного аккаунта Azure. Регистрация приложения ничего не стоит. **Не** подключайте платные тарифы.

## 1. Бесплатный аккаунт Azure

1. Откройте <https://azure.microsoft.com/free> и войдите своим аккаунтом Microsoft.
2. Пройдите проверку (телефон + карта). При этом автоматически создаётся каталог «Default Directory» — он нужен для регистрации приложения.

> Если при входе на portal.azure.com появляется ошибка вида *«учётная запись не существует в клиенте»* (AADSTS50020) — значит, этот шаг ещё не выполнен.

## 2. Зарегистрировать приложение

1. <https://portal.azure.com> → в поиске **«Регистрации приложений»** (App registrations) → **«Новая регистрация»**.
2. Имя: `Stray Client`.
3. Поддерживаемые типы учётных записей: **«Только личные учётные записи Майкрософт»** (Personal Microsoft accounts only).
4. Нажмите **«Зарегистрировать»**.
5. Скопируйте **«Идентификатор приложения (клиента)»** — это и есть Client ID (вида `1a2b3c4d-…`).

## 3. Разрешить вход из приложения

1. В приложении слева: **«Проверка подлинности»** (Authentication) → **«Добавить платформу»** → **«Мобильные и классические приложения»**.
2. Отметьте адрес перенаправления:
   `https://login.microsoftonline.com/common/oauth2/nativeclient`
   → **«Настроить»**.
3. Ниже включите **«Разрешить потоки общедоступных клиентов»** = **Да** → **«Сохранить»**.

## 4. Заявка в Mojang (обязательно)

Новые приложения должны получить разрешение на работу с Minecraft:

1. Откройте <https://aka.ms/mce-reviewappid>.
2. Укажите Client ID из шага 2 и коротко опишите проект: *«Stray Client — официальный клиент сервера StraySMP (лаунчер Minecraft на Rust, открытый код: github.com/MuMaFi/StrayClient)»*.
3. Одобрение может занять от нескольких дней до нескольких недель. До одобрения вход обрывается на последнем шаге — это нормально.

## 5. Передать Client ID

Client ID — **не секретный ключ**, его можно просто отправить в Telegram/Discord.
Либо сразу добавить его в GitHub:

**github.com/MuMaFi/StrayClient** → Settings → Secrets and variables → **Actions** → **New repository secret**
- Name: `STRAY_MSA_CLIENT_ID`
- Secret: Client ID из шага 2

После этого собирается новая версия Stray Client, и в ней появляется прямой вход через Microsoft. Игрокам достаточно обновиться.
